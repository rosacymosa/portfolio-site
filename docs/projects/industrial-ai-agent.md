# 工业时序故障诊断与运维LLM智能体
> ⚠️ Note：本项目所有数据均为 **Synthetic合成模拟数据集**，用于复现算法与工程流程，不使用任何企业真实设备/工单数据。

## 项目简介
模拟大型制造厂区设备在线监测场景；构建时序特征工程、故障检测模型，结合LLM+RAG故障知识库实现运维智能体，完成设备早期预警、点检任务自动生成。

**技术栈：Python｜PySpark｜SQL｜XGBoost｜小波包分解｜LLM‑RAG｜规则引擎｜Streamlit｜Plotly**

## 工作流程
1. 时序数据管道：模拟多传感器温振时序数据，做缺失值、异常值清洗，滑动窗口特征聚合
2. 信号特征提取：时域（RMS、峭度）+频域+小波包分解频段能量特征
3. 故障分类模型：随机森林 / XGBoost，模拟测试集召回率0.8，误报率控制10%以内
4. 运维智能体：规则引擎 + LLM‑RAG故障知识库，自动生成点检任务、维修建议
5. 可视化看板：模拟设备健康度看板，模型预警指标监控
