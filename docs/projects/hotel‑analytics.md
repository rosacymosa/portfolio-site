

# 综合度假村运营分析 & 订单取消预测
> ⚠️ Note：本项目全部使用 Synthetic合成模拟数据集，不包含真实酒店预订与客户评论数据。

## 项目简介
模拟综合度假酒店业务，整合客房、餐饮、活动预订多源数据，做ETL清洗、收益分析、订单取消预测、评论情感分析。

**技术栈：Python｜SQL Server｜Selenium｜spaCy｜BERT｜XGBoost｜SVM｜Tableau**

## 工作流程
1. ETL数据整合：模拟预订系统、邮件、评论多源原始数据；完成清洗、去重、格式统一，导入SQL。
2. 运营指标分析：入住率、ADR平均日房价、RevPAR每房收益，分析定价促销策略。
3. 订单取消预测：基于房型、预订提前期、消费特征，多模型对比，XGBoost效果最优，精度0.88，F1 0.84，AUC 0.96；用于高风险订单重售，降低收入损失。
4. 评论情感分析：模拟多平台英文用户评论，分词预处理，VADER/BERT做情感极性分析，词云提取高频反馈词。

## 模拟复现指标
- 优化定价策略后平均客房收益提升12%
- 基于取消预测干预，模拟减少18%收入损失
