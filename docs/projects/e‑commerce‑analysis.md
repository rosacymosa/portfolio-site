# 跨境美妆电商｜用户分层、流失预测、个性化推荐
> ⚠️ Note：本项目全部使用 Synthetic合成模拟数据集，仅演示数据分析流程，无真实业务用户数据。

## 项目简介
模拟跨境K‑beauty美妆电商业务，完成客户RFM分层、流失预测模型、协同过滤商品推荐，辅助精细化运营与营销活动。

**技术栈：Python｜Pandas｜Scikit‑learn｜XGBoost｜K‑Means｜Plotly｜Tableau**

## 工作流程
1. 用户分层：RFM模型对5万+模拟客户交易数据做特征提取，肘部法+轮廓系数确定聚类K值，K‑Means完成用户分群；针对不同分群做VIP激励、流失召回A/B测试。
2. 用户流失预测：提取注册渠道、套餐、行为特征，构建逻辑回归、随机森林、XGBoost流失预测模型；最佳模型Recall 0.76，AUC 0.82。
3. 商品推荐：基于协同过滤，构建用户‑商品交互矩阵，生成Top‑N个性化推荐列表，跟踪推荐点击率与转化。
4. 可视化：RFM分群散点图、留存热力图、ROC曲线、特征重要性图表。

## 模拟复现指标
- A/B测试带来会话时长+8%，点击率+20%，转化率+4.5%
- 流失干预后模拟整体流失率下降12%
- 个性化推荐点击率提升17%，用户满意度提升14%
